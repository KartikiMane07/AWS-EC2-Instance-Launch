# AWS EC2 Instance Launch

## Project Overview
This project demonstrates how to launch and configure an Amazon EC2 instance using the AWS Management Console.

## AWS Services Used
- Amazon EC2
- Amazon VPC
- Security Groups
- Key Pair

## Steps Performed
1. Logged in to the AWS Management Console.
2. Opened the EC2 Dashboard.
3. Launched a new EC2 instance.
4. Selected an Amazon Machine Image (AMI).
5. Chose the instance type.
6. Created/selected a key pair.
7. Configured the security group.
8. Launched the instance.
9. Verified that the instance was running.
10. Connected to the instance using SSH.

## Outcome
Successfully launched and configured an AWS EC2 instance.
